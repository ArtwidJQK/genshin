# Configuration System

This directory is reserved for static configuration, probability definitions, and rule definitions for future development phases.

## Scope & Future Responsibilities

- **Drop Tables & Weight Configurations**: Static configurations mapping item IDs to probabilities and weights.
- **Affix & Stat Definitions**: Schema and rules for artifact main stats and substats.
- **Gacha Pool Tables**: Probability curves, rarity buckets, and pity thresholds.

## Current Phase (P0 Foundation)

No game-specific configuration data or probability tables are active in P0. All configuration data systems will be introduced strictly in subsequent phases after the core probability and domain engines are validated.
